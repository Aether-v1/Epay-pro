# Epay Pro

基于彩虹易支付的聚合支付项目，提供商户支付接口、收银台、管理后台和插件式支付通道。本仓库还包含退款、转账与结算流程的维护代码，以及移动端支付页面的适配。

## 主要功能

- **聚合收款**：按支付方式和通道处理订单，提供商户接口、支付跳转、扫码支付和支付结果页。
- **插件扩展**：通过 `plugins/` 接入支付渠道；实际可用的支付方式取决于已配置的插件和通道。
- **商户与管理后台**：管理订单、支付方式、通道、结算及相关配置。
- **资金流程**：支持退款、转账和结算；包含 USDT-TRC20 手动结算选项。
- **安全相关实现**：包含管理员权限、操作审计，以及退款和转账状态处理。上线前仍需完成环境配置与业务验收。

## 运行环境

| 组件 | 建议 |
| --- | --- |
| PHP | 8.1 或更高版本；安装器最低检查版本为 7.4 |
| MySQL | 5.7 或 8.0 |
| Web 服务 | Nginx 或 Apache，需配置项目路由重写 |
| PHP 扩展 | `pdo_mysql`、`curl`、`gd`、`mbstring`、`openssl`、`fileinfo` |

请以实际部署环境验证 PHP 扩展、数据库版本和所启用支付插件的额外要求。

## 新站安装

1. 将仓库放到网站根目录，创建 MySQL 数据库，并为网站配置 HTTPS。
2. 配置路由重写。Nginx 可参考根目录的 [`nginx.txt`](nginx.txt)；IIS 可参考 [`IIS.txt`](IIS.txt)。同时限制外部访问 `config.php`、`includes/`、`plugins/`、`logs/` 和 `.git/`。
3. 确保网站进程可以在安装时写入 `config.php` 和 `install/install.lock`，然后访问 `https://你的域名/install/`，按页面提示完成安装。
4. **立即修改管理员密码。** 当前安装器创建的初始账号为 `admin`、初始密码为 `123456`；在修改前不要开放管理后台给外部使用。
5. 在后台配置支付方式、支付通道和商户信息，并验证下单、支付回调、退款及结算流程。
6. 安装完成后禁止外部访问 `install/`，收紧 `config.php` 的读写权限，确认上传目录不能执行 PHP。

`config.php.example` 给出了数据库配置格式；实际 `config.php` 包含凭据，已被 `.gitignore` 排除，不要提交到仓库。升级现有站点前，请先备份数据库和配置，并在测试环境核对 `install/` 中的升级与迁移脚本。

## BEpusdt 与支付方式图标

[`plugins/bepusdt/`](plugins/bepusdt/) 包含 BEpusdt 支付插件。插件支持多种加密货币及网络；启用前需要部署对应网关，并在支付通道中填写接口地址、认证 Token 等参数。

收银台按支付方式调用值读取 `assets/icon/<调用值>.ico`。本仓库为 BEpusdt 支持的九种 USDT 支付方式提供了图标，例如 [`usdt.trc20.ico`](assets/icon/usdt.trc20.ico)。插件目录中的 [`bepusdt.ico`](plugins/bepusdt/bepusdt.ico) 保存原始图标；USDC、TRX 等其他币种不会套用 USDT 标志。

## 项目目录

| 目录 | 用途 |
| --- | --- |
| `admin/` | 管理后台 |
| `user/` | 商户中心 |
| `includes/` | 公共逻辑与依赖 |
| `plugins/` | 支付插件 |
| `assets/`、`paypage/` | 静态资源与支付页面 |
| `install/` | 安装、升级和迁移脚本 |
| `docs/` | 部署参考资料 |

支付系统上线前，应使用实际通道完成端到端测试，并核对异步通知、重复回调、退款、转账和对账结果。
